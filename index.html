Mengenal Komponen Utama Komputer

Komputer bekerja dengan menghubungkan berbagai komponen fisik. Klik tombol-tombol komponen di bawah untuk mempelajari fungsi dan analoginya secara interaktif!

1. Komponen Utama (Hardware)

Pilih salah satu komponen di sebelah kiri untuk melihat gambar dan penjelasannya.

2. Sistem Komputer Lengkap

Sistem komputer tidak hanya hardware, tetapi juga terdiri dari perangkat lunak dan pengguna.

⌨️

Input Device (Masukan)

Perangkat untuk memasukkan perintah atau data ke komputer.

  • • Keyboard & Mouse
  • • Microphone & Kamera Web
  • • Scanner & Barcode Reader
🖥️

Output Device (Keluaran)

Perangkat untuk menampilkan hasil olahan data dari komputer.

  • • Monitor / Layar
  • • Speaker & Headphone
  • • Printer & Proyektor
👤

Software & Brainware

Perangkat lunak dan manusia yang mengoperasikan sistem.

  • • OS: Windows, Linux, Android
  • • Aplikasi: Word, Chrome, Canva
  • • Brainware: Programmer, User, Operator
